# excess

Bench projects. None are finished.

- `csi-presence` — ESP32-S3 room-presence experiment using Wi-Fi channel state information. Thresholds need retuning per room.
- `mouse` — paused RP2040 mouse experiment. The sensor firmware blob is not included; see the project files.
- `tcbfp` — Pong in Brainfuck, played in the browser.

[MorphCPU](https://github.com/ranveerlabs/morphcpu) is the one that made it out of the bench.
